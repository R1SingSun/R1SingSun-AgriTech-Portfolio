## 学习路径

```
Bitcoin          →  先把"钱怎么记账"这件事想透
  UTXO / Script / PoW
        ↓
Ethereum         →  再把"程序怎么在链上跑"想透
  账户模型 / EVM / Gas / MPT
        ↓
Hyperledger Fabric  →  最后落到企业级落地
  Peer / Orderer / CA / Channel / 私有数据
        ↓
我的项目：高州荔枝溯源小程序
```

## 三条链的一句话坐标

| | Bitcoin | Ethereum | Fabric |
| --- | --- | --- | --- |
| 定位 | 去中心化货币 | 去中心化计算机 | 企业级联盟链 |
| 记账模型 | UTXO | 账户余额 | 键值世界状态 + 区块链 |
| 共识 | PoW | PoS | Raft（可插拔） |
| 要不要钱 | 付手续费 | 付 Gas | 无代币、无 Gas |
| 准入 | 任何人 | 任何人 | **需要 CA 认证** |
